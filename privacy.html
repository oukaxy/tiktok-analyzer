Kebijakan Privasi

Terakhir diperbarui: 1 September 2026

Content Tracker ("aplikasi ini") adalah alat bantu pribadi untuk mencatat dan menganalisis performa konten TikTok milik penggunanya sendiri. Kebijakan ini menjelaskan data apa yang diakses, bagaimana data tersebut digunakan, dan di mana data tersebut disimpan.

1. Data yang Diakses

Saat pengguna menghubungkan akun TikTok melalui proses otorisasi resmi (OAuth), aplikasi ini dapat mengakses:

  • Informasi profil dasar (nama pengguna, foto profil)
  • Daftar video milik akun yang terhubung
  • Statistik performa video (jumlah tayangan, suka, komentar, share, dan simpan/save, jika tersedia melalui API)
  • Jumlah followers akun

2. Bagaimana Data Digunakan

Data yang diambil digunakan semata-mata untuk ditampilkan kembali kepada pengguna dalam bentuk pencatatan, grafik, dan ringkasan performa di dalam aplikasi — untuk membantu pengguna merencanakan dan mengevaluasi strategi kontennya sendiri.

3. Penyimpanan Data

Data yang diambil disimpan secara lokal di perangkat/browser pengguna (menggunakan penyimpanan lokal browser). Aplikasi ini tidak mengirimkan atau menyimpan data pengguna ke server pihak ketiga mana pun, dan tidak membagikan data kepada pihak lain.

4. Data yang Tidak Dikumpulkan

Aplikasi ini tidak mengumpulkan data pribadi sensitif, tidak melacak aktivitas pengguna di luar aplikasi, dan tidak menggunakan cookie pelacakan pihak ketiga atau layanan analitik/iklan eksternal.

5. Akses Token & Keamanan

Token akses yang diberikan TikTok saat proses otorisasi digunakan hanya untuk mengambil data dari API TikTok atas nama pengguna yang bersangkutan, dan disimpan secara lokal di perangkat pengguna. Pengguna dapat mencabut akses ini kapan saja melalui pengaturan aplikasi pihak ketiga di akun TikTok mereka.

6. Penghapusan Data

Karena seluruh data disimpan lokal di perangkat pengguna, pengguna dapat menghapus seluruh data kapan saja dengan menghapus data browser/aplikasi terkait, atau mencabut otorisasi dari pengaturan akun TikTok.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan tercermin pada tanggal "Terakhir diperbarui" di atas.

8. Kontak

Pertanyaan terkait kebijakan privasi ini dapat diarahkan ke pengembang aplikasi melalui kontak yang tertera di akun developer TikTok terkait.
